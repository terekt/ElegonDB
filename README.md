# Elegon DB

A fan-made database for the MMO **Elegon**: every item, creature, quest, drop table and map,
plus a character planner and a page of the game's own scaling curves.

Everything here is read out of the game's own tables and client code, or measured from
recorded play. Nothing is hand-written lore.

This repository holds the **built site only** — it is the published output of a private
workspace, rebuilt and force-published rather than edited here. Pull requests against these
files cannot be merged upstream, but issues about wrong numbers are very welcome.

Served by GitHub Pages from the root of `main`.
